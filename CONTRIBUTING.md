# Contributing

Thanks for your interest in the Percy Visual Testing Agent!

**This repository is a release mirror.** Its contents are published as versioned
snapshots, and its history is replaced on each release — so pull requests opened
here can't be merged and may disappear when a new version lands.

- 🐛 **Found a bug or have a feature request?** Please [open an issue](../../issues) —
  we read all of them.
- 💬 **Need help using the plugin?** See the README, or reach out via
  [BrowserStack Support](https://www.browserstack.com/contact).
- 🔒 **Security issue?** See [SECURITY.md](SECURITY.md) — please don't open a public issue.
